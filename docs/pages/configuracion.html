Seguridad

Esta versión no incluye inicio de sesión. Cualquier persona que conozca la dirección del sistema podría usarlo hasta que el backend implemente autenticación.

Cuando el backend exija autenticación, cada petición se autorizará allí: el frontend no guarda contraseñas ni secretos.
